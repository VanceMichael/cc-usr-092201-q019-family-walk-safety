# 亲子健走安全联络

记录亲子健走中的监护、检查点和安全联络资料。

## 资料范围

领域资料位于 `fixtures/domain.json`，结构约定见 `contracts/domain.schema.json`。当前记录类型包括参赛家庭、监护授权、出发批次、检查点记录、安全事件、交接确认，状态示例为待核验 → 已出发 → 行进中 → 需协助 → 已交接 → 已闭赛。这些样例使用虚构标识，不含真实个人资料、账号或连接凭据。

已整理的业务事实：

- 赛事有两千组亲子家庭参加
- 家庭按多个组别分批出发
- 路线长且经过多个城市地标

## 本地校验

项目自带的测试会读取样例并检查领域标识、版本、记录类型、流程状态和事实说明。后续服务应继续兼容这份公开资料约定。
